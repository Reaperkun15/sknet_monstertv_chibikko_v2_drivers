# sknet_monstertv_chibikko_v2_drivers
MonsterTV VHに似ていますが、おそらくOEM品かと思われるカードです。たぶん俺以外にいないでしょうが、一応同じようなことを考えている同士の人のために、アーカイブを残しておきます。
Debianにのみ対応しています。

再生時には付属の`play-saa7133-v4l2_1.sh`を使用してください。
